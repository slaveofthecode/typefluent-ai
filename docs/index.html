Why TypeFluentAI?

Most AI tools optimize productivity. TypeFluentAI optimizes learning.


The objective is not to generate better English for you. The objective is to help you write better English by yourself.

Guide, don't replace

The AI is a teacher and coach. It explains, challenges and encourages — it never quietly rewrites everything for you.

Active practice

You think, write, understand your mistakes, and rewrite your own answers through deliberate practice.

Local & private

The model runs on your machine via a local provider. Your writing and learning history remain yours.

Built for professionals

Initially focused on software engineers and IT professionals: interviews, standups, technical writing and more.

The Learning Loop

The fundamental unit of learning — a deliberately designed cycle that turns every correction into practice.

Prompt

The coach presents a meaningful writing challenge with a clear learning objective.

Write

You produce your own response, uninterrupted, expressing your ideas independently.

Analyze

The coach prioritizes mistakes that offer real learning value — not every imperfection.

Understand

You learn why an important correction matters before being asked to practice it.

Rewrite

You reconstruct the improved version yourself, reinforcing understanding.

Practice

Corrections become deliberate practice through active typing.

Progress

You recognize real improvements: fewer repeated mistakes, greater confidence.

The Harness

How the project is built and documented — the source of truth behind TypeFluentAI.

The /.harness directory is the project's long-term memory. Rather than storing knowledge only inside AI conversations, every important decision is documented so that developers and AI agents reason consistently about the system.

"Every important architectural decision must be documented before implementation."
  • Project Manifest Mission, vision, problem, solution and non-goals of the project.
  • Learning Philosophy How the system teaches: principles, the learning loop, feedback and motivation.
  • Architecture Agent-Oriented design: the Learning Coach and specialized internal agents.
  • Architectural Decisions (ADRs) The chronological record of every accepted architectural decision.
  • Agent Guidelines Rules governing how AI coding agents contribute to the codebase.

Architecture

An Agent-Oriented Architecture with a single, purpose-built front door for the learner.

Learning Coach

The only component that talks to the user. It understands intent, delegates work, combines results and communicates feedback.

Internal Agents

Grammar analysis, vocabulary, exercise generation, progress tracking and more. They work behind the coach — never directly with the user.

Provider Abstraction

The application stays decoupled from any specific local LLM, so providers like Ollama are replaceable and configurable.

User → Learning Coach → Local LLM → Learning Coach → User
